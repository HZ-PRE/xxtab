xxtab — WireGuard + WebSocket 轻量客户端

适用于 Windows 10（1809 及以上）和 Windows 11，x64。

安装内容：图形界面、命令行客户端、私有 WireGuard 运行时及许可文件。配置模板内置于程序，无需额外示例文件。
默认安装到 Program Files\xxtab，可选择创建桌面快捷方式。

WireGuard：安装包包含从官方已签名 WireGuard 0.5.3 MSI 提取的私有运行时，仅由 xxtab 创建和管理隧道服务。不会安装或启动独立的 WireGuard 桌面客户端，也不会修改本机已有的 WireGuard。

安装完成后，打开 xxtab，导入或新建配置，再点击连接。默认 remote 为 127.0.0.1:7007，表示 wstunnel 服务端访问的 WireGuard 地址。

安装和运行需要管理员权限，用于管理 WireGuard 接口和路由。升级或卸载前，请先断开连接并正常退出客户端。

用户配置保存在当前用户的 %LOCALAPPDATA%\xxtab\profiles，卸载时保留。应用私有运行时会随 xxtab 删除；本机原有的 WireGuard 安装保持不变。若使用其他管理员账号授权运行，配置属于该管理员账号。
